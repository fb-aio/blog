Tìm dev

18/06/2024 · Social AIO Blog

Hiện tại để chuẩn bị cho version tới, mình sẽ chuyển hầu hết chức năng liên quan tới facebook sang 1 trang web mới.

Trang web này chạy độc lập bên ngoài extension Useful Script. Nhưng vẫn kết nối tới extension để có thể hoạt động.

Vì là web ngoài nên có thể dùng bất kỳ framework, thư viện nào tuỳ thích.

Hiện tại mình đang sử dụng Vite + ReactJs + Antd để code. giao diện max đẹp mà không cần code nhiều các bạn có thể thấy trong hình.

Nhưng mà vẫn thiếu 1 thứ đó là thời gian, 1 mình thì không thể đi xa được, nên mọi người ai có hứng thú, muốn đóng góp thì hãy tham gia nhé :)) luôn welcome mọi người.

repo github tại đây: https://github.com/Useful-Scripts-Extension/fbaio
