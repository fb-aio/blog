Tả.i được nhiều thông tin hơn với Facebook all in one

08/08/2024 · Social AIO Blog

Hỗ trợ tải .json rồi nha mọi người, trong file .json thì sẽ có thêm nhiều thông tin như toàn bộ link ảnh/video, id ảnh/video/bài viết, tên file sẽ lưu, nội dung bài viết (caption), số like / comment / share ...

Phù hợp cho bạn nào muốn lấy thông tin để “làm việc khác” :)))

Sẵn mình cũng cập nhật lại trang chủ, hiện chút Giới thiệu và Lịch sử cập nhật.
