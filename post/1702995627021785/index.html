Ad vừa test thử, cơ chế của web này là: 🤖 Server tự động cào dữ liệu từ những group/page được user…

04/08/2025 · Social AIO Blog

Ad vừa test thử, cơ chế của web này là:

  • 🤖 Server tự động cào dữ liệu từ những group/page được user chọn
  • 🙈 Định kỳ (mỗi ngày) sẽ cào bài viết, thành viên, bình luận, lượt thích, ....
  • 👀 Kết hợp thêm AI để phân tích bài viết, thông tin, ...
  • 🖼 Rồi lưu vào database riêng, thành 1 dashboard cho từng group/page
  • 📈 Khi user mở web thì sẽ lấy dữ liệu từ database ra hiển thị

Mình dùng thử, và mới thêm group FB AIO hôm qua, nên dữ liệu chỉ có 2 ngày hôm qua và hôm nay 😅 => web chưa cào được data cũ

🌟Ý tưởng hay và phù hợp cho ai muốn phân tích group/page bất kỳ

👀 Thường thì bạn phải là admin của group/page thì mới xem được những thông tin thống kê này

Mình share cho mọi người test thử thôi, chứ không tích hợp vào FB AIO đâu 😂
