Những kênh giải trí hay cho Dev 🌟

09/12/2024 · Social AIO Blog

Để duy trì cảm hứng code, mình thường xem những kênh tin tức dưới đây, MỖI NGÀY:

  1. Github Trending: những dự án code đang nổi 👀
  2. Fireship: cà khịa công nghệ, 100s để hiểu 1 ngôn ngữ bất kỳ 🤖
  3. Sebastian Lague: nâng trình XEM người ta code 😁
  4. Code Bullet: vừa code vừa hài 🤡
  5. The Coding Train: Code gì dễ dữ vậy 🤓
  6. Stackoverflow Trend: Xem ngta hỏi gì nhiều nhất 🤪
  7. Chatgpt: Hãy hỏi "fact về lập trình ít người biết" thử xem 🤣

Trong đó The coding train là kênh đầu tiên dẫn mình vào ngành lập trình, phù hợp cho những bạn mới 🤣

Ai chuyên nghiệp hơn rồi thì có thể xem những kênh còn lại 🌟
