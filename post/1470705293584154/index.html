Codium: Code chung với AI

22/08/2024 · Social AIO Blog

Có bao giờ mọi người tự hỏi, sao thằng này nó code nhanh thế nhỉ, chức năng mới ra liên tục, trong khi nó vẫn đi làm công ty 8 tiếng/ngày ???

Có tips hết đó mọi người. Đó là mình không code 1 mình, mình code chung với AI :v

https://codeium.com

  1. Con AI này giúp mình code nhanh hơn nhiều, tự nhắc code, còn có chat có thể hỏi như hỏi chatgpt, nhưng thông minh hơn chatgpt do nó có thể đọc hết code của bạn và hiểu bạn đang muốn gì, còn chatgpt thì mình phải tự giải thích cho nó, nhiều khi nó còn chả hiểu 🥴😅
  2. Hỗ trợ rất nhiều ngôn ngữ lập trình, hầu như mọi ngôn ngữ mình đã học nó đều hỗ trợ. Đang code javascript, chuyển qua html nó cũng hiểu luôn. 😙
  3. Hỗ trợ rất nhiều IDE (thứ để viết code), đang code bằng vscode, nhảy qua sublime text, xong nhảy qua xcode, nó chơi được hết.🥹
  4. MIỄN PHÍ, MIỄN PHÍ, MIỄN PHÍ không như ai kia (github copilot) mất tận 10$/tháng. Thằng này miễn phí cho người dùng đơn lẻ, chỉ tính phí khi code theo nhóm (công ty).🤤

Mình dùng nó hơn 1 năm rồi, và thấy cực kỳ xứng đáng. Khuyên dùng, khuyên dùng, khuyên dùng. 😂
