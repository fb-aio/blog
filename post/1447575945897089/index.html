13/07/2024 · Social AIO Blog

Cách thường dùng nhất để không bị "đạo code" đó là làm rối/mã hóa code của chính mình, để người khác không đọc hiểu được code nữa.

Người khác vẫn có thể copy, ăn trộm, nhưng sẽ khó có thể chỉnh sửa, fix lỗi. Và nếu trong code có chèn thêm kiểm tra license, tự động hết hạn, ... Thì có trộm cũng không xài được lâu.

Nhưng vỏ quýt dày có móng tay nhọn.
Trang web dưới đây sẽ giúp bạn "làm đẹp" lại code javascript bị làm rối. Rất thích hợp cho những bạn thích vọc code của người khác 🤐

Phù hợp nhất để vọc chrome extension, nodejs code.

https://deobfuscate.relative.im
