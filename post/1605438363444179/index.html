Hoverify 4.0 - All in One extension for Developer 👀

18/03/2025 · Social AIO Blog

Tiện ích này chứa rất nhiều chức năng hữu dụng cho Dev hoặc Designer:

  • 🔎 Inspector: Kiểm tra / Xuất code HTML và CSS nhanh chóng
  • 🌈 Color Eyedropper: Lấy màu từ trang web
  • 📱 Responsive Viewer: Kiểm tra responsive cho mọi web
  • 📌 Site stack: Xem web dùng công nghệ gì
  • 📈 SEO: Kiểm tra các thuộc tính SEO
  • 🏞️ Assets: Xuất tất cả ảnh/video từ website

  • 📸 Capture: Chụp màn hình bất kỳ phần tử nào trên web
