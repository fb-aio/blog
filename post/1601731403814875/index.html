Nửa đêm khó ngủ, vì Trae IDE xịn quá 🫥

13/03/2025 · Social AIO Blog

Trae gần giống Cursor, cũng tạo 1 IDE riêng dựa trên mã nguồn mở VsCode, tích hợp thêm AI để hỗ trợ lập trình 🤖

p/s: Trae do công ty mẹ của top top tạo ra đó 👀

Trae hiện tại miễn phí, nhưng model AI cũng xịn không kém Cursor. Mình chỉ prompt cho Trae biết mình cần gì, nó gen hết code từ đầu tới cuối cho mình luôn 👀

Bên dứoi là trang web thống kê logs truy cập FB AIO, có gọi api, hiển thị log, tạo biểu đồ, css html js, tính toán ... đủ thứ luôn, mà mình không cần động 1 dòng code nào, thấy sai hoặc chưa ưng ý chỗ nào thì hú Trae sửa là xong 🤯 Chat với Trae nửa tiếng xong cái web

AI giờ mạnh quá, không học nhanh thì tụt hậu mất 🫥
