JSON Crack - Hiển thị JSON bằng biểu đồ

22/08/2024 · Social AIO Blog

Làm việc với JSON không còn phải đui con mắt để nhìn nữa. Phù hợp với các loại JSON nhiều tầng (lồng nhiều object)

Tool này vẽ lại JSON (YAML, XML, CSV) dứoi dạng biểu đồ phân tầng dễ nhìn, dễ quản lý.

Bản web có giới hạn size JSON (trả phí), còn vscode extension thì không giới hạn.

github: https://github.com/AykutSarac/jsoncrack.com

website: https://jsoncrack.com

vscode extension: https://marketplace.visualstudio.com/items?itemName=AykutSarac.jsoncrack-vscode
