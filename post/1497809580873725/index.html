***ENGLISH
*NEW: View Protected Facebook Profiles**

Yesterday, I asked people to let me experiment with locked personal profiles.
Luckily, I was able to uncover a bit—not photos or posts yet—but something even more interesting: tag activity 📌. I’ve turned it into a feature that everyone can use.

View Tag Activity: Find out where someone has been tagged across Facebook (posts, comments):

  • Who tagged them 👤
  • What the tag content is 📝
  • You can even open it directly on Facebook 🔗
  • Even if their profile is locked, you can still see this 🔓

This is a great way to stalk your crush thoroughly 👀!

Additionally, some older features that you might have overlooked:

  • View the list of groups the person has joined
  • View the list of pages the person likes Both features also work even if the profile is protected!
