Codex + 1 prompt = Web xịn xò quá ae 🤯

13/03/2026 · Social AIO Blog

Này là UI xịn nhất từ trước đến giờ, mà mình có thể làm đc với 1 prompt (đã test gemini, claude, qwen, ...) 🤖

Không chỉ đẹp, mà nó còn chạy đc mọi chức năng mà mình mong đợi :v không crash, ko lỗi ngay lần prompt đầu tiên 👀

Tạo mới +3000 dòng code chỉ với 1 prompt + plan mode 😇

Con Codex này có phần quản lý skills riêng luôn, cài app là có mấy skills ngon để dùng rồi không cần cài thêm gì nhiều 🌟

Đã vậy limit còn cao nữa, xài xả láng chưa thấy limit gì luôn, như claude dùng 3 prompt là hit limit rồi đó 🤣
