Lỗi mới từ phở bò - Too many requests 👀

15/11/2025 · Social AIO Blog
  • Phở bò đang bắt đầu thắt chặt các hành vi tự động 🫥
  • 429 là status code mới, rất dễ dính 😇
  • ad đã thêm cơ chế bắt status code này, và tự động chờ 15s rồi mới thử lại API 👀

Nhưng cũng chỉ tạm né được phần nào thôi, vẫn dính nhé, nên ae dùng cẩn thận 🥹 nếu dính thì thực hiện các bước sau:

  • ⬆️ Tăng thời gian chờ
  • ⬇️ Giảm số luồng tải
  • 🔄 Đổi IP / kết nối VPN
  • 🆔 Đổi trình duyệt / profile (đổi fingerprint browser)
